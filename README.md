# WatchHub — MERIDIAN

A luxury watch scrollytelling experience. Scroll to disassemble and reassemble the timepiece — a cinematic frame-by-frame canvas animation built with Next.js 16, React 19, Tailwind v4, and Framer Motion 12.

## Live Demo

**[https://meridian3d.netlify.app](https://meridian3d.netlify.app)** — view it in the browser.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) for local development.
